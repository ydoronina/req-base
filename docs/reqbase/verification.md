HTTP-проверка выполнена внутри приложения: стандартный запуск сетевого процесса в тестовой среде завис на Windows socketpair, а автоматическая проверка разрешения на отдельный локальный запуск не завершилась вовремя. Проверка stdio использовала реальный дочерний процесс с тестовым циклом событий без сетевых сокетов. Полный штатный `unittest` на этой конфигурации не завершился; результаты выше относятся к выполненным сценариям, а не ко всему набору тестов.

Открытая проверка для стенда с Kroki: открыть проект в браузере, проверить четыре схемы и русские подписи, сформировать BRD/SRS с рисунками, скачать Markdown/PDF и проверить, что рисунки и кириллица читаемы. Нагрузочные цели, допустимая потеря данных и время восстановления из требований N01/N06 ещё не измерялись.

В файловом комплекте `requirements.md` содержит каталог и Mermaid, `reqbase-project.json` — снимок для восстановления. `exercise.py` загружает и проверяет черновик в чистом экземпляре ReqBase; он не перезаписывает одноимённый проект.
