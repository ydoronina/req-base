# Знания о ReqBase

## Решения по первому релизу

- ReqBase рассчитан на одного аналитика и его ИИ-ассистента. Аналитик согласует требование, выставляя `Approved` в веб-интерфейсе или давая ассистенту явную команду. Согласование отдельного снимка BRD/SRS не требуется. Проверка наличия команды аналитика относится к работе ассистента. Сервер принимает допустимое значение статуса через MCP.
- MCP пишет напрямую. `dry_run` доступен для предварительного прогона. Аудит и откат требуются для отдельных требований. Откат добавляет событие в историю.
- При выборе веток приложение SRS включает активные схемы, связанные с выбранными требованиями или их потомками, которые проходят фильтры статусов. Общая схема добавляется в приложение один раз. Без выбора веток включаются все активные схемы проекта.
- Фильтр «Только Approved» сейчас отбирает ровно `Approved`. Включение `Implemented` в согласованный состав, целевая нагрузка и параметры резервирования остаются открытыми вопросами.
